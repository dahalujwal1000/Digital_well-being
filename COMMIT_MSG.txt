v1.2: one-click Windows app packaging (build_exe.bat)

- New build_exe.bat builds two standalone executables with PyInstaller:
  DigitalWellbeingTracker.exe (background tracker + tray) and
  DigitalWellbeingDashboard.exe (dashboard window)
- Exes are self-contained (Python + deps bundled); data still lives in
  %APPDATA%\DigitalWellbeing so they can be copied to any Windows PC
- Verified end-to-end: built both exes, ran tracker exe for 6s, confirmed
  it opened a session and wrote app rows to the SQLite DB
- README: "Install as a Windows app" section; .gitignore: *.spec
