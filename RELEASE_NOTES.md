# Digital Wellbeing for Windows v1.3.2

Digital Wellbeing is a lightweight Windows desktop app that tracks time spent in desktop apps and websites, then presents the data in a clear daily dashboard.

## Highlights

- Refreshed, Android Digital Wellbeing-inspired dashboard with clearer spacing, typography, and navigation.
- Daily overview with screen-time ring, active/open/idle time, unlock count, hourly activity, and top apps.
- Dedicated Apps & websites, Sessions, and Weekly views with search, filters, and date navigation.
- More reliable tracking around suspend, resume, day rollover, and database writes.
- Improved app attribution, dashboard empty states, autostart behavior, and installer startup flow.

## Install

1. Download `DigitalWellbeing-v1.3.2-windows-x64.zip`.
2. Extract the entire archive to a permanent folder.
3. Open the `DigitalWellbeing` folder and run `DigitalWellbeing.exe`.
4. Use the system-tray icon to open the dashboard or manage tracking.

## Requirements

- Windows 10 or Windows 11, 64-bit.
- This is a portable package. It does not add a Start menu shortcut; autostart can be managed from the tray menu.

## Notes

Usage data is stored locally in `%APPDATA%\\DigitalWellbeing\\wellbeing.db`.
